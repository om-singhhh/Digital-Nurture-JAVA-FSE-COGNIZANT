# Cognizant Java Full Stack Engineering (Java FSE) - Training Repository

## Overview

This repository is organized module-wise so each training area can be updated independently as the work progresses. The folders at the root represent the major module groups, and the `UpSkilling` folder contains the smaller topic-wise exercises for the course.

## Language Prerequisites

Before starting the modules, it helps to be comfortable with these basics:

- Core Java syntax, variables, loops, and conditions
- Object-oriented programming concepts such as classes, objects, inheritance, and polymorphism
- Basic SQL query writing, including `SELECT`, `INSERT`, `UPDATE`, and `DELETE`
- HTML, CSS, and JavaScript fundamentals for the frontend exercises
- Using an IDE like VS Code, IntelliJ IDEA, or Eclipse for writing and running code
